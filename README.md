# Login System Basic PHP

A simple **Login System** built using PHP, MySQL, HTML, and CSS. This project demonstrates basic user authentication and database connectivity using PHP and MySQL.

## 🚀 Features

* User login form
* Username and password validation
* MySQL database connection
* Basic authentication
* Error handling
* Simple CSS styling

## 🛠️ Technologies Used

* PHP
* MySQL
* HTML
* CSS
* XAMPP
* phpMyAdmin

## 📂 Project Files

* `index.php` – Login form
* `login.php` – Processes login requests
* `db_conn.php` – Database connection
* `style.css` – Login page styling
* `test_server.sql` – Database SQL file

## 🗄️ Database

Database name:

`test_server`

Table:

`users`

You can manage the database through phpMyAdmin:

[Open Database in phpMyAdmin](http://localhost/phpmyadmin/index.php?route=/database/structure&db=test_server)

## ▶️ How to Run

1. Install and start **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Place the project inside the XAMPP `htdocs` folder.
4. Import `test_server.sql` into phpMyAdmin.
5. Check the database connection in `db_conn.php`.
6. Open the project in your browser:

`http://localhost/Login-System-Basic-Php/`
